# 🔐 Projeto GRC – POSIC para Fintech (ABC-Fin)

## 📌 Sobre o Projeto

Este projeto apresenta o desenvolvimento de uma Política Corporativa de Segurança da Informação (POSIC) para a empresa fictícia ABC-Fin, com base em conceitos de Governança, Riscos e Compliance (GRC).

---

## 🏢 Cenário

A ABC-Fin é uma fintech que opera com:
- Aplicativo móvel e portal web  
- Dados financeiros e pessoais sensíveis  
- Infraestrutura em nuvem
